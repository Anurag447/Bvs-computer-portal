# BVS Computer Coaching – Student Management System

🚀 **Project Overview**  
This is a **Student Management System** developed for **BVS Computer Coaching, Behta Gokul (Hardoi)** using **PHP (Core), MySQL, jQuery & AJAX**.  
The project allows students and admins to manage profiles, attendance, marks, and other details in a secure and responsive environment.

---

## 🛠️ **Technologies Used**
- **Backend:** PHP Core  
- **Database:** MySQL  
- **Frontend:** HTML, CSS, JavaScript  
- **AJAX & jQuery:** For dynamic content updates  
- **Responsive Design:** Works on desktop & mobile  

---

## 🎯 **Features**

### Student Dashboard:
- View profile details  
- Check attendance and marks  
- Responsive and user-friendly UI  

### Admin Panel (Optional / Planned):
- Manage students, courses, and batches  
- Attendance tracking  
- Marks management  
- Fees tracking and notices
